# Publishing the Braintrust provider

The public Terraform Registry requires a **public** GitHub repository named `terraform-provider-braintrust`, a signed GitHub release, and a one-time Registry registration. This repository is currently GitHub **internal**, has no release tags, and has no release-signing secrets. Do not push a version tag until those prerequisites are complete. Publishing a provider to the public Registry is a lasting public commitment.

1. Have a Braintrust GitHub organization admin review the repository for public release and change its visibility to public. Decide whether to publish under the `braintrustdata` Registry namespace. Keep the provider source address in examples as `braintrustdata/braintrust`.
2. Create an organization-controlled RSA GPG signing key. Add its ASCII-armored public key to the `braintrustdata` namespace in the Terraform Registry. Store its private key and passphrase as the repository's `GPG_PRIVATE_KEY` and `GPG_PASSPHRASE` GitHub Actions secrets. The [release workflow](.github/workflows/release.yml) imports these secrets and passes the signing fingerprint to GoReleaser.
3. Review the documentation and choose a SemVer version. Run `goreleaser check` against [`.goreleaser.yml`](.goreleaser.yml). The config produces ZIP archives, a Registry manifest, a checksum file containing the archives and manifest, and a detached signature. The manifest declares Terraform plugin protocol `6.0`.
4. From an up-to-date `main`, create and push the first tag, for example `git tag v0.1.0` and `git push origin v0.1.0`. The release workflow should publish a GitHub release with `terraform-provider-braintrust_0.1.0_<os>_<arch>.zip`, `terraform-provider-braintrust_0.1.0_manifest.json`, `terraform-provider-braintrust_0.1.0_SHA256SUMS`, and `terraform-provider-braintrust_0.1.0_SHA256SUMS.sig`. Check that the workflow passed and the release is not a draft.
5. Sign in to the [Terraform Registry](https://registry.terraform.io/) with a GitHub account authorized for the Braintrust organization. Choose **Publish → Provider**, select the `braintrustdata` namespace and this repository, and complete registration. The Registry creates a GitHub release webhook for later versions.
6. Verify from a clean directory that `terraform init` downloads `braintrustdata/braintrust` at the released version without a development override. Then update the installation and agent-starter docs to remove the pre-publication instructions.

See HashiCorp's [provider publishing requirements](https://developer.hashicorp.com/terraform/registry/providers/publishing) for the current signing, naming, asset, and Registry UI details. If the repository must stay private, use an [HCP Terraform private provider registry](https://developer.hashicorp.com/terraform/enterprise/registry/publish-providers) instead; it is a different distribution path and does not make `registry.terraform.io/braintrustdata/braintrust` available to the public.
