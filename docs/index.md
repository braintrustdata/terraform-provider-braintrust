# Braintrust Provider

The Braintrust provider allows you to manage [Braintrust](https://www.braintrustdata.com/) resources such as projects, experiments, datasets, and more.

## Authentication

The provider requires a Braintrust API key for authentication. You can create an API key in the Braintrust [organization settings page](https://www.braintrustdata.com/app/settings?subroute=api-keys).

The API key can be provided in the provider configuration block or via the `BRAINTRUST_API_KEY` environment variable.

## Example Usage

```terraform
terraform {
  required_providers {
    braintrust = {
      source = "braintrustdata/braintrust"
    }
  }
}

# Configure the Braintrust provider.
# The API key can also be set via the BRAINTRUST_API_KEY environment variable.
provider "braintrust" {
  # api_key = "your-api-key-here"
  # api_url = "https://api.braintrust.dev"  # optional, defaults to this
}
```
